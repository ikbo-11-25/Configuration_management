# Практическая работа №1. Вариант 30

Этап 1: графический прототип UNIX-оболочки на Python и Tkinter.
Заголовок содержит реальные username и hostname. Парсер разделяет
ввод по пробелам; ls и cd пока выводят имя и аргументы. Команда exit
закрывает окно. Неизвестные команды выводят сообщение об ошибке.

## Запуск

Требуется Python 3.10+ с Tkinter. Windows: `run.bat`.
Linux/macOS: `sh run.sh`. Сборка и сторонние пакеты не требуются.

## Тесты

Windows PowerShell:

```powershell
$env:PYTHONPATH = 'src'
python -m unittest discover -s tests -v
```

Linux/macOS:

```sh
PYTHONPATH=src python3 -m unittest discover -s tests -v
```

## Интерактивная демонстрация

```text
ls /tmp
cd /home
unknown
exit extra
exit
```

Ошибки unknown и exit extra не закрывают окно.

## Этап 2. Конфигурация

`--vfs PATH` задает источник VFS (подключение в этапе 3).
`--startup PATH` задает UTF-8 сценарий. Пустые строки и строки с #
пропускаются. При первой ошибке или exit выполнение останавливается.
В окне показываются ввод и вывод каждой команды. После ошибки окно
остается открытым. `conf-dump` выводит все настройки как ключ=значение.
Настройки также показываются при запуске.

`--headless` - дополнительный режим запуска сценария без окна для тестов.
Требует `--startup`; код завершения: 0 при успехе, 1 при ошибке сценария,
2 при ошибке аргументов. Скрипты ОС: examples/demo-config.bat и .sh.

```bat
run.bat --vfs examples\vfs\deep --startup examples\scripts\stage2.txt
```

## Этап 3. VFS

При запуске каталог из --vfs читается в память: файлы хранятся как bytes,
каталоги - как узлы дерева. Никакие команды не записывают данные в источник.
Поддержаны абсолютные и относительные UNIX-пути, . и ..; / - корень VFS.
Ссылки, junction и специальные файлы отклоняются; источник должен быть
обычной доступной директорией. Владельцы в VFS инициализируются именем
текущего пользователя, группа - users. Это виртуальные метаданные.

Примеры VFS: minimal (один файл), files (несколько файлов), deep
(docs/course/tasks/task.txt, три уровня папок). Скрипты ОС:
examples/demo-vfs.bat и .sh; сценарий эмулятора: scripts/stage3.txt.
ls и cd на этом этапе еще являются заглушками; логика появится в этапе 4.

## Этап 4. Основные команды

ls [путь ...]: список содержимого или имя файла; -a включает скрытые
имена и . / .., -l показывает виртуальные права, владельца, группу,
размер и дату. -al и -la объединяют режимы; -- завершает опции.
cd [путь]: смена каталога; без пути переходит в /, cd - возвращается
в предыдущий каталог и печатает путь. Неверный cd не меняет состояние.
cal: текущий месяц; cal МЕСЯЦ ГОД: заданный месяц; cal ГОД или
cal -y [ГОД]: весь год. Диапазоны: месяц 1..12, год 1..9999.
who: текущая сессия эмулятора, реальный пользователь и имя компьютера.
Список всех системных сеансов других пользователей не запрашивается.

examples/demo-core.bat и .sh запускают демонстрации. stage4.txt
показывает все режимы, затем ошибку cd; отдельные сценарии проверяют
ошибки cal и ls. Более полная проверка ошибок находится в tests.
